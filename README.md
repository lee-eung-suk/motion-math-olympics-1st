# 🎿 수학 동계올림픽 (초등 1학년 2학기)

**초등학교 1학년 2학기 수학 교과 연계 · 모션인식 기반 웹 교육 게임**

태블릿을 책상 위에 놓고 앉은 채로, 손을 움직이거나 고개를 기울이거나 태블릿을 터치하거나 PC에서 마우스로 조작하며 즐기는 6종목 동계올림픽 테마의 수학 미니게임 모음입니다. 별도 설치 없이 웹 브라우저에서 바로 실행되며, 학생 개인이 60초 동안 각 종목의 기록에 도전합니다.

---

## 📖 소개

이 프로젝트는 초등 1학년 2학기 수학 교과 단원(100까지의 수, 덧셈과 뺄셈(1)(2)(3), 모양과 시각, 규칙 찾기)을 동계올림픽 6개 종목으로 재구성한 웹 애플리케이션입니다. `motion-math-olympics`(2학년용) 프로젝트의 엔진과 화면 구조를 그대로 가져와 만들었습니다.

학생들이 **책상 위에 태블릿을 두고 앉은 자세로 플레이**하는 것을 기준으로, 손동작(가리키기·쓸기·조준·양손 들기)과 고개 움직임(좌우 기울이기)만으로 조작할 수 있도록 모든 동작을 설계했습니다.

## ✨ 주요 특징

- **3가지 조작 방식**: 모션인식(카메라로 손·고개 동작 인식) / 터치 모드(태블릿) / 마우스 모드(PC) 중 선택 가능
- **자동 난이도 조절**: 정답을 연속으로 맞히면 난이도가 올라가고, 연속으로 틀리면 낮아지는 자동 조절 시스템
- **하이라이트 자동 저장**: 플레이 중 가장 잘한 순간의 사진과 3초 영상을 자동으로 만들어 기기에 저장 가능 (서버에는 저장되지 않음)
- **완전 반응형**: PC, 태블릿, 모바일 어떤 화면 크기·가로/세로 방향에서도 사용 가능
- **오프라인 친화적 설계**: 손동작 인식에 필요한 AI 모델을 자체 서버에 내장해, 학교 네트워크 환경에서도 안정적으로 동작

## 🎮 6개 종목 소개

| 종목 | 이름 | 학습 주제 | 조작 방식 |
|---|---|---|---|
| 1 | 빙판 위의 수 스케이터 | 100까지의 수 | 1인칭 시점으로 내 양발 스케이트를 보며, 고개를 좌/우로 기울여 더 큰 수·짝수 코스를 골라요 |
| 2 | 10 만들기 컬링 | 덧셈과 뺄셈(1) | 십틀(10칸)에 채워진 수를 보고 `6 + ? = 10`의 빈칸 수를 찾아, 그 수가 적힌 링에 스톤 하나를 굴려요 |
| 3 | 피겨 여왕의 모양 연기 | 모양과 시각 | 손끝에서 빛 리본이 흐르고, 하단의 피겨 스케이터가 함께 활주해요. 목표 모양을 손으로 만져 모아요 |
| 4 | 타겟 탕탕! 덧뺄셈 바이애슬론 | 덧셈과 뺄셈(2) | 정답 표적을 손으로 조준해 0.6초 유지하면 명중! |
| 5 | 규칙 타고 멀리 점프! | 규칙 찾기 | 1인칭 시점의 스키를 신고 달리다가, 속도가 가득 차면 양손을 번쩍 들어 도약해요(만세) |
| 6 | 골키퍼를 뚫어라! 파워 슛 | 덧셈과 뺄셈(3) | 날아오는 퍽 중 정답 퍽에 손을 대서 슛해요 |

각 종목은 60초 동안 진행되며, 콤보·최고 기록에 따라 동/은/금 메달이 주어집니다.

## 🛠 기술 스택 (개발 정보)

- **프레임워크 없는 순수 HTML/CSS/JavaScript** (별도 빌드 과정 불필요)
- **[MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe)**: 손/얼굴 랜드마크 인식 (자체 서버에 wasm·모델 파일 내장)
- **Canvas 2D API**: 카메라 영상 합성 및 게임 렌더링
- **Vercel**: 정적 사이트 배포

## 📁 프로젝트 구조

```
motion-math-olympics-1st/
├── index.html            # 랜딩(종목 선택) 화면
├── games/                 # 종목 1~6 게임 화면
│   ├── u1-number.html
│   ├── u2-curling.html
│   ├── u3-figure.html
│   ├── u4-biathlon.html
│   ├── u5-skijump.html
│   └── u6-hockey.html
├── js/
│   ├── engine.js          # 카메라·인식·사운드·기록 등 공통 엔진 (2학년판과 동일)
│   └── vision_bundle.mjs  # MediaPipe 번들
├── css/style.css           # 전체 스타일(반응형 포함)
├── assets/                 # 이미지·사운드 에셋
├── models/                  # MediaPipe AI 모델 파일
├── wasm/                    # MediaPipe wasm 런타임
└── vercel.json               # 배포 설정
```

단원 썸네일(`assets/Thumbnail1~6.png`)은 아직 준비되지 않았습니다. 같은 파일명으로 이미지를 넣으면 랜딩 화면 카드에 자동으로 반영되고, 그 전까지는 종목 이모지 플레이스홀더가 대신 표시됩니다.

## 💻 로컬에서 실행하기

```bash
cd motion-math-olympics-1st
python3 -m http.server 8621
```

브라우저에서 `http://localhost:8621` 접속. (카메라 권한이 필요한 모션인식 모드는 `localhost` 또는 HTTPS 환경에서만 정상 동작합니다.)

## 🔄 최근 변경 (2026-08-10)

수업 현장 피드백을 반영해 4개 종목을 손봤습니다. 자세한 배경은 [수정제안서.md](수정제안서.md) 참고.

- **종목 1·5 — 1인칭 시점**: 이모지 캐릭터를 없애고, 내려다본 내 양발(스케이트·스키)을 Canvas 벡터로 그립니다. 날 자국·속도선·눈가루가 속도에 연동되고, 스키점프는 도약 순간 지평선이 내려가며 스키가 멀어지는 1인칭 연출로 바뀌었습니다.
- **종목 2 — 난이도 완화**: 스톤 3개의 점수를 더해 10을 만드는 방식(초1에게 세 수의 덧셈)을 없앴습니다. 십틀에 채워진 수를 보여주고 **10의 보수 하나만** 맞히면 되며, 스톤은 **1개**만 던집니다(기회 2번). 하우스는 동심원 3개 링으로 나뉘고 각 링에 숫자와 점(●)을 함께 표시해, 글을 못 읽어도 세어서 고를 수 있습니다. 메달 기준도 함께 조정(동 5 / 은 9 / 금 13).
- **종목 3 — 피겨다운 연출**: 떠다니던 스케이트 신발 한 짝 커서를 없애고, 손끝을 따라 흐르는 빛 리본과 하단의 피겨 스케이터 실루엣(아라베스크·스핀)으로 교체했습니다.
- **공통**: 안내 문구를 1학년이 읽기 쉬운 표현으로 바꾸고, 하단 문구가 1인칭 발/캐릭터에 가려지지 않도록 상단 배너로 옮겼습니다.

> 하우스를 부채꼴 4구역으로 나눈 초안은 폐기했습니다. 스톤이 직선으로만 굴러가 좌·우 구역에는 닿을 수 없어, 정답이 그 구역에 놓이면 클리어가 불가능했기 때문입니다.
